## ✅ **Answer Key – Mock Test #8**

### 🧠 **Section 1: Advanced Scripting & Performance**

1. **B.** It avoids floating-point precision errors  
   - `Mathf.Approximately(a, b)` is used to compare floats safely, accounting for small precision differences.

2. **C.** `OnRenderObject()`  
   - Called after rendering is complete, useful for custom rendering logic.

3. **A.** To manually trigger garbage collection  
   - `GC.Collect()` forces garbage collection, but should be used cautiously as it can cause performance spikes.

4. **C.** Can cause frame spikes due to synchronous loading  
   - `Resources.Load()` loads assets synchronously, which can block the main thread and cause performance issues.

5. **A.** `[Range(min, max)]`  
   - This attribute draws a slider in the Inspector for float or int fields.

---

### 🎮 **Section 2: Architecture, Systems & Scene Management**

6. **A.** Use `PlayerPrefs`  
   - `PlayerPrefs` is commonly used for saving simple persistent data like settings or scores.

7. **B.** To package and load assets at runtime  
   - `AssetBundles` are used to load assets dynamically, especially in large or modular games.

8. **C.** `Static Batching`  
   - Combines static meshes to reduce draw calls and improve rendering performance.

9. **B.** To limit the frame rate of the game  
   - `Application.targetFrameRate` sets the desired frame rate cap for the application.

10. **A.** Use `#if UNITY_EDITOR`, `#if UNITY_ANDROID`, etc.  
   - Preprocessor directives allow platform-specific code compilation.

---

### 🧩 **Section 3: UI, Input & Events**

11. **A.** Use `CanvasScaler` with `Scale With Screen Size`  
   - Ensures UI scales properly across different screen resolutions.

12. **A.** To detect if the pointer is over any UI element  
   - `EventSystem.current.IsPointerOverGameObject()` helps prevent UI and game world input conflicts.

13. **A.** `ContentSizeFitter`  
   - Automatically adjusts the size of UI elements based on their content.

14. **C.** `rectTransform.DOAnchorPos()`  
   - Animates the anchored position of UI elements using DOTween.

15. **A.** Implement `IDragHandler`  
   - This interface allows you to respond to drag events on UI elements.
